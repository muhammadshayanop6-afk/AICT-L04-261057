# Project Information

## Project Name
Student Helpdesk Ticket Process

## Project Description
A group project of the IT Services to plan and document how student helpdesk tickets are received, categorised, answered and closed. The plan covers three phases: plan and purchase, install, and test and train users. The approved budget is PKR 310,000 and the go-live date is 21 December 2026.
